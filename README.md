# Программа обработки вещественных матриц

Консольное приложение на Python меняет местами строки, содержащие глобальный
минимальный и глобальный максимальный элементы вещественной матрицы.

## Возможности

- ввод прямоугольной матрицы произвольного размера;
- проверка количества строк и длины каждой строки;
- поиск глобальных минимума и максимума;
- перестановка соответствующих строк;
- сохранение матрицы без изменений, если оба экстремума находятся в одной строке.

## Требования

- Python 3.11 или новее;
- Git для работы с репозиторием;
- `flake8` только для проверки стиля при разработке.

## Запуск

```bash
python src/matrix_processor.py
```

Программа запрашивает количество строк, затем принимает элементы каждой строки,
разделённые пробелами.

## Проверка

```bash
python -m unittest discover -s tests -v
flake8 src tests
```

## Структура репозитория

- `src/` — исходный код;
- `tests/` — автоматические тесты;
- `docs/` — техническое задание и проектная документация;
- `.github/workflows/` — конфигурация непрерывной интеграции;
- `.github/ISSUE_TEMPLATE/` — шаблон сообщения об ошибке.

## Стратегия ветвления

Используется упрощённый Git Flow. Ветка `main` содержит проверенное состояние
проекта, а `develop` служит для объединения разрабатываемых изменений. Новые
функции можно создавать в короткоживущих ветках от `develop`. После успешных
тестов изменения сливаются в `main`, а готовая версия отмечается тегом.
