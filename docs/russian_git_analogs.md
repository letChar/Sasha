# Российские аналоги платформ для Git

## GitFlic

Российская DevOps-платформа для хранения кода и совместной разработки. Доступна
в облачном и локальном вариантах, поддерживает привычный рабочий процесс Git.
В Едином реестре российского ПО указана под № 15861. Преимущества: локальное
развёртывание и ориентация на российские организации. Ограничение: экосистема
интеграций меньше, чем у GitHub.

## GitFlame

Сервис хранения репозиториев с версионным контролем для разработчиков и DevOps-
инженеров, построенный на Git. В реестре указан под № 21590. Преимущество —
совместимость со стандартными командами Git. Ограничение — меньшая известность
и количество сторонних интеграций по сравнению с крупными зарубежными сервисами.

## Gitlife Enterprise

Модульная платформа управления жизненным циклом проектов с модулем «Код» на
основе Git. В реестре указана под № 29396. Преимущество — объединение управления
кодом с другими этапами жизненного цикла. Ограничение — избыточность комплексной
платформы для небольшого учебного проекта.

## Deckhouse Code

Решение для непрерывной разработки и управления жизненным циклом программного
обеспечения. Поддерживает хранение кода и CI/CD, в реестре указано под № 27871.
Преимущество — связь репозитория с процессами сборки и доставки. Ограничение —
более высокая сложность внедрения по сравнению с обычным хостингом репозитория.
