# План тестирования

## Цель

Проверить корректность поиска экстремальных элементов, перестановки строк и
обработки некорректной структуры матрицы.

## Набор автоматических тестов

| № | Проверяемая ситуация | Ожидаемый результат |
|---|---|---|
| 1 | Минимум в первой, максимум в последней строке | Первая и последняя строки меняются местами |
| 2 | Оба экстремума в одной строке | Матрица не изменяется |
| 3 | Отрицательные и дробные значения | Строки определяются по числовым значениям |
| 4 | Пустая матрица | Возникает `ValueError` |
| 5 | Строки разной длины | Возникает `ValueError` |

## Команды проверки

```bash
flake8 src tests
python -m unittest discover -s tests -v
```

Эти же команды выполняются в GitHub Actions для веток `main` и `develop`, а также
для Pull Request в `main`.
