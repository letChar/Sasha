# Архитектура программы

## Назначение

Программа принимает прямоугольную вещественную матрицу, находит глобальные
минимум и максимум и меняет местами строки, в которых расположены эти элементы.

## Компоненты

Модуль `src/matrix_processor.py` разделён на три части:

1. `_validated_copy` проверяет непустую прямоугольную структуру и создаёт копию.
2. `swap_extreme_rows` выполняет однопроходный поиск экстремумов и перестановку.
3. Функции `_read_positive_integer`, `_read_matrix` и `main` образуют консольный
   интерфейс и отвечают за обработку пользовательского ввода.

Автоматические тесты находятся в `tests/test_matrix_processor.py`. Конфигурация
GitHub Actions запускает проверку стиля и тесты после отправки изменений.

## Алгоритм

Матрица просматривается построчно. Для каждого элемента сравниваются текущее
минимальное и максимальное значения и запоминаются индексы соответствующих строк.
После завершения прохода строки обмениваются одновременно. Если индексы совпадают,
матрица остаётся без изменений.

Временная сложность алгоритма составляет `O(n × m)`, дополнительная память для
результирующей копии — `O(n × m)`.
