# Архитектура программы

## Назначение

Программа принимает прямоугольную вещественную матрицу, находит глобальные
минимум и максимум и меняет местами строки, в которых расположены эти элементы.

## Компоненты

1. `matrix_input.py` считывает матрицу, проверяет ввод и формирует JSON-запрос.
2. `json_protocol.py` отвечает за чтение и атомарную запись сообщений версии 1.0.
3. `matrix_processor.py` проверяет матрицу, находит экстремумы и переставляет строки.
4. `matrix_output.py` проверяет JSON-ответ и выводит результат.
5. `main.py` последовательно вызывает компоненты и обрабатывает ошибки.

Модульные тесты находятся в `tests/test_matrix_processor.py`, сквозные проверки —
в `tests/test_integration.py`. GitHub Actions запускает линтер, тесты и измерение
покрытия после отправки изменений.

## Алгоритм

Матрица просматривается построчно. Для каждого элемента сравниваются текущее
минимальное и максимальное значения и запоминаются индексы соответствующих строк.
После завершения прохода строки обмениваются одновременно. Если индексы совпадают,
матрица остаётся без изменений.

Временная сложность алгоритма составляет `O(n × m)`, дополнительная память для
результирующей копии — `O(n × m)`.
