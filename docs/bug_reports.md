# Отчёты об ошибках

## BR-01. Нечисловой элемент в матрице ответа

- Шаги: записать в JSON-ответ матрицу `[[1], ["broken"]]` и вызвать
  `read_response`.
- Ожидалось: `ProtocolError`.
- Было: файл принимался.
- Исправление: добавлена проверка формы матрицы, типов и конечности чисел.
- Статус: исправлено, добавлен регрессионный тест.

## BR-02. Устаревший файл ответа после ошибки

- Шаги: оставить успешный `response.json`, записать повреждённый запрос и
  запустить `process_request_file`.
- Ожидалось: ошибка без старого ответа.
- Было: старый файл оставался на диске.
- Исправление: предыдущий ответ удаляется перед обработкой нового запроса.
- Статус: исправлено, добавлен регрессионный тест.
