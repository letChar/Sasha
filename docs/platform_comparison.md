# Сравнение GitHub и GitFlic

| Критерий | GitHub | GitFlic |
|---|---|---|
| Размещение | Международная облачная платформа | Российская облачная и локальная платформа |
| Совместная работа | Issue, Pull Request, ревью, проекты | Задачи, запросы на слияние, ревью |
| CI/CD | GitHub Actions и каталог готовых действий | Встроенные средства CI/CD |
| Экосистема | Очень большое сообщество и число интеграций | Меньшая экосистема, ориентация на российский рынок |
| Развёртывание в организации | GitHub Enterprise | Доступен локальный вариант |
| Реестр российского ПО | Не относится к российскому ПО | Включён в реестр под № 15861 |

Для учебного проекта выбран GitHub: он предоставляет единый интерфейс для
репозитория, Pull Request, шаблонов Issue и автоматизации GitHub Actions. GitFlic
является подходящей отечественной альтернативой, особенно когда требуется
локальное развёртывание и использование продукта из Единого реестра российского ПО.
