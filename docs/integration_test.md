# Интеграционное тестирование

## Проверяемые сценарии

1. Полный обмен через JSON с перестановкой первой и последней строк.
2. Сохранение порядка, если минимум и максимум находятся в одной строке.
3. Отклонение пустой и непрямоугольной матрицы.
4. Отклонение повреждённого JSON и неизвестной версии схемы.
5. Ошибка при отсутствии файла запроса.
6. Прерывание при нулевом тайм-ауте.
7. Проверка успешного и ошибочного пути координатора `main.py`.
8. Проверка форматированного вывода результата.

## Команды

```bash
python -m unittest discover -s tests -v
coverage run --source=src -m unittest discover -s tests
coverage report -m
```

Актуальные числовые результаты фиксируются в журнале GitHub Actions для каждого
коммита. Workflow завершает работу с ошибкой, если покрытие ниже 90 процентов.
