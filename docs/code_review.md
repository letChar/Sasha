# Результаты проверки кода

Проверка проведена перед выпуском версии 1.0.1.

## Найденные замечания

1. В README оставались номер версии 0.1.0 и неверная команда запуска отдельного
   модуля. Указана версия 1.0.0 и команда `python -m src.main`.
2. Тест координатора завершался успешно независимо от результата. Он заменён
   проверками успешного выполнения, тайм-аута и ошибки входных данных.
3. Не было отдельной сквозной проверки обмена через оба JSON-файла. Добавлен
   `tests/test_integration.py`.
4. Два workflow использовали разные версии Python и разные пороги покрытия.
   Интеграционный workflow переведён на Python 3.12 и порог 90 процентов.
5. Отсутствовали документы с контрактом интеграции, тестовыми сценариями и
   сравнением стратегий. Документы добавлены в каталог `docs`.

## Итог

После исправлений `flake8` не выдаёт замечаний, модульные и интеграционные тесты
проходят, а покрытие проверяется автоматически в GitHub Actions.
