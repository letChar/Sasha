# Сравнение методов тестирования

| Метод | Достоинства | Ограничения | Применение в проекте |
|---|---|---|---|
| Причинно-следственный анализ | Показывает связь условий и реакций | Требует точного описания правил | Основной метод варианта 13 |
| Эквивалентное разбиение | Сокращает число похожих тестов | Может пропустить граничную ошибку | Группы допустимых и недопустимых матриц |
| Граничные значения | Находит ошибки у границ | Не проверяет всю логику | Пустая матрица, один элемент, нулевой тайм-аут |
| Белый ящик | Контролирует ветви и исключения | Зависит от реализации | Покрытие строк и ветвей `src` |

Для работы выбрано сочетание методов: основой набор построен по
причинам и следствиям, а покрытие ветвей подтверждает полноту проверки.
